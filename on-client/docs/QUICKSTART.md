# 헤세드 실행 안내 한 장

처음 보는 사람이 이 한 장만 보고 헤세드(보안 Agent 앱)를 켜고 「내 PC 관제」를 확인하는 순서입니다. 더 자세한 설명은 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md)에 있습니다.

## 준비물

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10/11 (방화벽·Windows 기록 조회는 Windows에서만 됩니다) |
| Node.js | 24.19.0 권장(22~24). PowerShell에서 `node -v` 로 확인합니다. 없으면 https://nodejs.org 에서 LTS 를 설치합니다 |
| 외부 패키지 | 없음 (`npm install` 이 필요 없습니다) |
| 관리자 권한 | 필요 없음. 관리자 권한으로 실행하지 않습니다 |

## 1. 앱 폴더에서 PowerShell 열기

파일 탐색기에서 `on-client` 폴더(안에 `package.json` 과 `student` 폴더가 있는 곳)를 엽니다. 위쪽 주소창을 한 번 누르고 `powershell` 을 입력한 뒤 Enter 를 누릅니다.

## 2. 앱 켜기

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

- 정상 시작 신호: 창에 `케셰브 연결 확인: http://127.0.0.1:5189` 가 보입니다.
- 화면 모양만 보고 싶으면 끝에 ` -Demo` 를 붙입니다. 이때 기기·세션·기록은 **예제 자료**이고, 「내 PC 관제」의 PC 값만 실제로 잰 값입니다.
- 이 창은 앱을 쓰는 동안 닫지 않습니다.

## 3. 브라우저로 열기

PC 브라우저에서 `http://127.0.0.1:5189` 를 엽니다. 왼쪽 메뉴 「보호 현황」의 「학생 상태·알림 표시」 칸 맨 위 **헤세드 내 PC 관제** 에서 **다시 조회** 를 누릅니다(키보드: Tab 으로 버튼에 간 뒤 Enter).

| 화면에 보이는 것 | 뜻 |
|---|---|
| 이 PC 실측 | 방금 이 PC에서 잰 값. 잰 시각이 함께 적힙니다 |
| 확인 불가 | 값을 읽지 못함(이유와 다음 할 일이 함께 보임). 정상이나 안전이 아닙니다 |
| 오래됨 · 현재 값 아님 | 1분보다 오래된 값. 다시 조회합니다 |
| SDP 미연결 | 회사 접근 제어 서버(SDP)에 연결하지 않은 기본 실행. 정상 표시입니다 |
| 주의 관찰 | 기준을 넘은 관찰과 그것만으로 말할 수 없는 것. 판정이 아닙니다 |

## 4. 끄기와 다시 켜기

- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl+C`.
- 다시 켜기: 2번 명령을 다시 실행하고 브라우저를 새로 고칩니다. 추이와 조회 기록은 저장하지 않으므로 처음부터 다시 쌓입니다.

## 막혔을 때

| 증상 | 할 일 |
|---|---|
| `node` 를 찾을 수 없음 | Node.js 를 설치한 뒤 **새** PowerShell 창을 엽니다 |
| 실행 정책 오류 | 명령을 그대로(`-ExecutionPolicy Bypass` 포함) 붙여 넣었는지 확인합니다. 시스템 설정은 바꾸지 않습니다 |
| 5189 포트를 이미 사용 중 | 이미 켜진 앱 창이 있는지 확인하고 그 창에서 `Ctrl+C` 로 끈 뒤 다시 켭니다 |
| 「다시 조회」 뒤 조회 실패 | 앱을 켠 창이 열려 있는지 확인하고 다시 조회합니다. 계속되면 「도움정보 불러오기」 결과를 담당자에게 보여 줍니다 |
| 방화벽·Windows 기록이 확인 불가(권한 없음) | 관리자 권한으로 바꾸거나 보안 설정을 고치지 않습니다. 그대로 두고 필요하면 담당자에게 확인합니다 |

API 키·비밀번호·토큰은 이 앱의 어떤 칸에도 입력하지 않습니다.
